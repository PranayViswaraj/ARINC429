# ARINC 429 Verilog Implementation

This repository contains Verilog implementations and testbenches for ARINC 429 avionics communication protocol.

## Project Files

### Source Modules
- **arinc429_controller.v** - Main controller module
- **arinc429_rx.v** - Receiver module
- **arinc429_tx.v** - Transmitter module
- **arinc429_fault_injector.v** - Fault injection module for testing

### Testbenches
- **tb_arinc429_controller_review1_fix.v** - Controller testbench
- **tb_arinc429_rx_review1_fix.v** - Receiver testbench
- **tb_arinc429_tx_review1_fix.v** - Transmitter testbench
- **tb_arinc429_fault_injection.v** - Fault injection testbench

## Phase 1 - Active Development

Current focus on core ARINC 429 protocol implementation with comprehensive testing and fault injection capabilities.

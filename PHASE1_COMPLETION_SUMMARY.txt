================================================================================
KNOWN LIMITATIONS (DOCUMENTED)
================================================================================

By Design (Not Defects):
  ✅ Single-parity protection cannot detect even-parity errors
     → Two-bit faults undetectable (2/2 verified as expected)

  ✅ No timeout detector in RTL
     → Timeout detection deferred to software health monitor

  ✅ No label validator in RTL
     → ARINC label validation deferred to application layer

  ✅ No FIFO in RTL
     → FIFO behavior modeled in testbench for health classification

Mitigations for Review-3:
  • Application-level checksums or interleaving for multi-bit error detection
  • Software timeout monitor on rx_valid assertion
  • Label validator in firmware stack
  • FIFO framework for buffering multiple transactions
